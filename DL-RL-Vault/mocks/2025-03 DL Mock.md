## Open questions (Q11–Q13)

**Q11** (3pts): Explain the concept of backpropagation in the context of training deep learning models. What is its purpose, and how does it work?

**Q1:** Convolutional layers. (Transformers use self-attention, positional encoding, and FFN — but no convolutions.)

**Q2:** GANs. (Implicit generative models — define a sampling procedure but not a likelihood. The others all define $p(x)$ tractably or via lower bound.)

**Q3:** "To find the parameters of a model that minimize the loss function."

**Q4 (*):** ✅ "approximate the intractable true posterior" + ✅ "serve as a lower bound on the log-likelihood". (The ELBO is both — used as objective AND derived as $\log p(x) - \mathrm{KL}(q\|p)$.)

**Q5:** "Using stochastic gradient descent (SGD) for optimization." (SGD's noise is implicit regularization. L2 = explicit. More layers ≠ regularization. Noise injection in data is closer to explicit.)

**Q6:** "To generate samples that are indistinguishable from real data." (Same as 2024 Q5.)

**Q7 (*):** ✅ "model memorizes training data too well" + ✅ "mitigated by regularization". The other two are wrong (overfitting *hurts* test performance and is *less* common in simple models).

**Q8:** "To gradually add noise to the data." (In diffusion: encoder = forward / noising process; decoder = reverse / denoising.)

**Q9:** "To prevent vanishing and exploding gradients during training." (Xavier/He initialization is designed for this.)

**Q10:** "The phenomenon where the performance of a model degrades as the number of features increases." (Strictly speaking, classic statistical/ML phrasing — distances become uniform in high $d$, volume concentrates near corners, etc.)

**Q11:** Backpropagation = chain rule applied to a computational graph to compute $\nabla_\phi \mathcal{L}$ efficiently. Two passes: **(i) forward** — compute activations layer by layer, store intermediates; **(ii) backward** — propagate $\partial\mathcal{L}/\partial \text{output}$ backward through the graph, multiplying by local Jacobians (using the chain rule). Cost: $O(\text{forward pass})$ thanks to amortization across all parameters.

**Q12:** Linear regression normal equations. Setting $\nabla L = 0$:
$$\begin{cases} \partial L/\partial \phi_0 = 2 \sum_i (\phi_0 + \phi_1 x_i - y_i) = 0 \\ \partial L/\partial \phi_1 = 2 \sum_i (\phi_0 + \phi_1 x_i - y_i) x_i = 0 \end{cases}$$
Let $\bar x = \tfrac{1}{I}\sum x_i$, $\bar y = \tfrac{1}{I}\sum y_i$. Solving:
$$\phi_1^* = \frac{\sum_i (x_i - \bar x)(y_i - \bar y)}{\sum_i (x_i - \bar x)^2}, \qquad \phi_0^* = \bar y - \phi_1^* \bar x.$$

**Q13:** Same as 2024 Q13. Case split on sign of $z$. ✓
