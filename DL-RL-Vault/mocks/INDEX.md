## How to use this

1. **First pass:** read the questions, attempt each one with the vault notes closed.
2. **Second pass:** for questions you couldn't answer, open the linked notes and study.
3. **Third pass:** verify against the answer key.
4. **Failure log:** keep a running list of questions you got wrong — these are your priority topics.
